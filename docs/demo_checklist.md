# 课堂演示与用户验收步骤

本清单用于用户亲自演示和验收；不是已经执行的人工操作记录。自动化实际结果见 `reports/test_report.md`。

1. 根据 README 安装依赖并启动，确认窗口能正常显示。首次使用应为空账本，不自动填充假数据。
2. 选择一个月份，添加餐饮 12.30 元、交通 2.00 元、餐饮 0.10 元及餐饮 0.20 元。核对本月合计 14.60 元，餐饮合计 12.60 元、交通合计 2.00 元。
3. 选中交通记录，将 2.00 改为 3.00，合计应为 15.60 元。尝试删除并先取消，确认记录保留，再确认删除，合计变为 12.60 元。
4. 输入 0、负数、三位小数、空金额，确认提示错误且账本不增加记录。尝试超长备注，确认有明确限制。
5. 关闭并重新打开相同数据库，确认记录仍在。
6. 设置该月预算 15.00 元，核对剩余金额；增加消费使总额等于及超过预算，观察提醒变化。切换月份，确认预算与流水不会串月。
7. 切换分类，核对显示流水与所选分类一致；确认预算仍按全月总额计算。切回全部分类，确认全部流水恢复。
8. 导出 CSV，用文本编辑器或表格软件查看中文表头、两位小数与导出记录。筛选后导出，确认范围与界面一致。
9. 尝试备注以 `=`、`+`、`-`、`@` 开头及包含逗号/引号/换行，检查 CSV 正确转义且不把备注作为表格公式执行。

分享截图和发布博客前，请检查是否包含真实个人消费记录；项目提供的测试/预览数据是合成数据。
