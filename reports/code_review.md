- 存储层使用参数化 CRUD、独立连接、事务提交/回滚和异常包装，没有发现主动覆盖数据库、误删其他月份或把用户输入作为 SQL 执行的路径。

## 保留的设计限制

- 切月、切筛选及刷新清空未保存草稿；预算设置/清除后的刷新也会清空消费表单。README 已明确，草稿保护仍是可选体验改进。
- SQLite 和 CSV 在 GUI 线程中操作，大文件或锁等待期间可能阻塞界面；当前面向个人规模数据，未承诺后台任务或压力指标。
- CSV 原子替换保护正常错误下的旧文件，不等于已验证突然断电的完整目录持久性，也没有承诺恶意并发替换路径时的安全性。
- 月流水、预算及导出各次读取不是跨进程同一事务快照；外部并发修改时导出依据重新读取的数据库，可能与先前表格快照不同。
- 人工篡改/不兼容数据库 schema、跨平台/DPI/人工视觉验收未由本静态报告确认。最终通过率、实际平台和测试限制以 TestEngineer 最终报告为准。
